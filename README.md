# grow-bench — م0: قياس سرعة تدريب موديل لغوي عربي على CPU

قياس حقيقي (مش تقدير) لسرعة تدريب موديل لغوي صغير **بدون كارت شاشة**، على سيرفر 4 أنوية.

- `bench.py` — موديل transformers صغير (byte-level، ~4M باراميتر) يتدرّب على نص عربي حقيقي من **mC4 العربي** (عبر HuggingFace datasets-server)، ويقيس **كلمات/ثانية** ثم يستنتج الأقصى الممكن.
- `docker-compose.yml` — يشغّله في كونتينر محدود (2 threads، 4 دقايق تدريب).

**المخرجات:** `tokens_per_sec` · الخسارة قبل/بعد مقابل عشوائي (`ln 256`) · ساعات لكل 100M توكن.
